# PC057 defense candidates near predicted prophages in Desulfovibrio

This repository links the analyses and archived inputs to the 28 October 2026 Microbial Genomics manuscript. It provides a qproj-based R/Quarto workflow for checking frozen results, exporting the contents of Tables S1–S21 and inspecting the figures. Parameterised source for the scientific revision is retained separately.

The adopted catalogue comprises 436 genomes, 6,937 defense calls, 493 separate anti-defense calls and 5,217 name-matched merged defense candidates (T3). PDC-S31 is associated with predicted prophage neighbourhoods in a limited set of lineages; these records do not establish defense activity or transfer. The manuscript's scientific results are unchanged by this code release.

## Start here

Requirements: R 4.5 or newer, Python 3.11 or newer, the R packages in `DESCRIPTION`, and Pandoc or Quarto. Python helpers use the standard library only. The tested package graph is recorded in `renv.lock`; qproj is pinned to `rujinlong/qproj@4665814be79e13f7440f26b95279c014e6a5e209`.

From the repository root, install the declared dependencies in R, or restore the recorded package graph:

```r
install.packages("renv")  # only if renv is not already installed
renv::restore(lockfile = "renv.lock", prompt = FALSE)
```

The lockfile was captured from the tested local library. A fresh-machine restore has not been tested; operating-system libraries and fonts are not locked by renv. The report driver loads a restored project library when `renv/library/` exists and passes the same library paths to its child R checks.

Prepare the compressed, hash-registered inputs and run the frozen workflow:

```sh
python3 dev/prepare_inputs.py
Rscript --vanilla dev/render_notebooks.R
```

If Pandoc is supplied by Quarto but is not on PATH, set `PC057_PANDOC` to that installation's Pandoc executable. `PC057_PYTHON` can select a Python executable. These are executable-path settings, not data locations.

The driver executes the R expressions in the numbered QMD files through knitr and writes GitHub Markdown through Pandoc. The eleven QMD files are the editable sources and the eleven adjacent Markdown files are reports generated by actual execution. The selected PNG previews are the outputs of those runs; S2 is copied from its archived canonical image.

The native Quarto route is also supplied:

```sh
quarto render analyses --to gfm --execute --no-cache
```

In the release environment, native Quarto executed the first notebook but could not finish its temporary-directory cleanup because of filesystem restrictions. All eleven notebooks were therefore validated through the knitr/Pandoc driver; successful native Quarto completion is not claimed.

## Reproducibility scope

The supported default workflow verifies the 72 saved payload files, compares ten saved RDS components to CSV exports, exports all 21 supplementary tables and the six sets of spatial margins, redraws Figures 1–5 and S1, and copies archived Figure S2. It performs no model fitting, bootstrap resampling, annotation, sequence alignment or database update.

The original sequences, complete annotation environments and full historical database are external. Saved ecology model objects are supplied; complete fitted outgroup objects were not retained, although coefficient tables are included. Figure S2's underlying marker metadata and trees are supplied, but the default workflow does not infer those trees again. Current redraw jitter has a fixed display seed; historical fonts, package versions and unspecified jitter prevent a claim of pixel-identical rendering for every figure.

The full/clone × 0/5/10 kb S19 export contains 177 strata. S7 uses activity-carrier scope labels; its historical saved RDS retains earlier labels, which are checked against the previous export. The reporting CSV gives their corrected meaning. See [reproducibility details](docs/reproducibility.md).
