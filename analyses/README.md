# Analysis workflow

Run input preparation from the repository root before the notebook driver. Steps use `clean = FALSE`, a private staging directory inside their own qproj target, and verified shared inputs under `data/00-raw/d00-resource/pc057/`. They never write to the source SQLite database.

| Step | Purpose |
| --- | --- |
| [010-verify-inputs](010-verify-inputs.qmd) | Verify all prepared frozen inputs |
| [020-export-tables](020-export-tables.qmd) | Export Tables S1 to S21 from frozen records |
| [030-verify-saved-results](030-verify-saved-results.qmd) | Compare ten saved RDS result components with CSV exports |
| [040-export-spatial-margins](040-export-spatial-margins.qmd) | Export and verify full and clone spatial margins |
| [110-figure1-cohort](110-figure1-cohort.qmd) | Redraw fig1_cohort from frozen records |
| [120-figure2-catalog](120-figure2-catalog.qmd) | Redraw fig2_catalog from frozen records |
| [130-figure3-enrichment](130-figure3-enrichment.qmd) | Redraw fig3_enrichment from frozen records |
| [140-figure4-neighborhood](140-figure4-neighborhood.qmd) | Redraw fig4_neighborhood from frozen records |
| [150-figure5-outgroup](150-figure5-outgroup.qmd) | Redraw fig5_outgroup from frozen records |
| [160-figureS1-ecology](160-figureS1-ecology.qmd) | Redraw figS1_ecology from frozen records |
| [170-figureS2-terl](170-figureS2-terl.qmd) | Redraw figS2_terl from frozen records |

QMD files are the editable sources. Adjacent Markdown reports were generated by executing these sources through the provided knitr/Pandoc driver. The driver changes only chunk-option syntax for knitr; it does not rewrite R expressions.

Examples from the repository root:

```sh
python3 dev/prepare_inputs.py
Rscript --vanilla dev/render_notebooks.R
Rscript --vanilla dev/render_notebooks.R 030-verify-saved-results
```

The 020 step writes 21 CSV tables and an export manifest under `data/020-export-tables/tables/`. It reproduces table contents, not the formatting of the author-edited submission workbook. The 030 step compares all ten saved result components; it does not recompute P values. The 040 step exports 177 spatial strata and checks saved n, x and expectations without calculating a new test.

The six redraw steps produce PNG/PDF outputs; the S2 step copies the original PNG. Only the seven PNG previews are tracked; data unpacking, receipts and bulk outputs are ignored by Git.

Shared resources are read-only. `path_data` is reserved for step-private raw inputs; `path_source` reads earlier outputs where needed; `path_target` identifies the current step output. Every step has a UUID and validates its configured output location.
